# 🧠 Memory Match Game

A fun and interactive memory card matching game built using HTML, CSS, and JavaScript.

## ✨ Features

- 🃏 Interactive memory cards
- 🔄 Card flip animation
- ⏱️ Timer
- 👣 Moves counter
- 🏆 Pair tracking
- 🔀 Randomized cards
- 🌙 Dark mode
- 📱 Responsive design
- 🎉 Winning message

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🎮 How to Play

1. Click on a card to reveal it.
2. Click on another card to find its matching pair.
3. If both cards match, they remain open.
4. If they don't match, they flip back.
5. Match all the pairs to complete the game.

## 📌 Project Purpose

This project was created to practice and demonstrate basic web development concepts including HTML structure, CSS styling, DOM manipulation, JavaScript event handling, and game logic.
